## Qué hago

Programo juegos y aplicaciones web. Mi experiencia profesional está en Unity y C# para juegos 2D de PC (sistemas de juego, interfaces y herramientas de editor), y en la web trabajo con HTML5, CSS3, JavaScript, PHP y SQL.

- **Juego:** Unity, C#, Unreal Engine, prototipado, UI, herramientas de editor, depuración y rendimiento.
- **Web:** HTML5, CSS3, JavaScript, PHP, MySQL y MariaDB, Git.
- **Aprendiendo ahora:** Angular, React, ASP.NET Core, SQL Server, Azure y AWS, en el Máster en Desarrollo Full Stack y Arquitecturas Cloud de Fundación Tajamar.
